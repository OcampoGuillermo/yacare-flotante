# Yacaré

un yacaré overo de Formosa que conoce la provincia de punta a punta: su historia, sus ciudades, su gente y su naturaleza.

Agente flotante para Android y compu hecho por Guillermo Ocampo con la plantilla «agente-flotante» (DIA, copyleft).

- Android: https://github.com/OcampoGuillermo/yacare-flotante/releases/latest/download/Yacare.apk
- Windows: https://github.com/OcampoGuillermo/yacare-flotante/releases/latest/download/Yacare-Windows.zip
